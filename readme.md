# Neovim 自定义快捷键说明
chatgpt帮忙按照配置文件生成的基础版本，后续等待优化哈

## 文件操作
- `⌘S / ⌥S / S` → 保存文件
- `⌘W` → 关闭当前窗口


## 导航与编辑
- `J / K` → 上下快速移动 5 行
- `;` → 快速进入命令模式
- `` ` `` → 切换大小写

## 剪贴板
- `Y / ⌘C` → 复制到系统剪贴板
- `⌘V` → 从系统剪贴板粘贴（支持普通、插入、命令、终端模式）

## 窗口管理
- `<leader>w` → 切换到下一个窗口
- `<leader>h/j/k/l` → 移动到左右上下窗口
- `qf` → 关闭其他窗口
- 方向键 → 调整窗口大小（↑↓ 高度，←→ 宽度）

## 分屏管理
- `sj/sk/sh/sl` → 下/上/左/右 分屏
- `sh/sv` → 强制水平/垂直布局
- `srh/srv` → 旋转分屏

## 标签页管理
- `⌘T` → 新建标签并打开 Yazi
- `⌘J / ⌘K` → 上一个/下一个标签
- `⌘⇧J / ⌘⇧K` → 标签左移/右移
- `⌘数字 (1~9)` → 切换到第 N 个标签页

## 杂项
- `⌥Z` → 切换自动换行
- `⌘← / ⌘→` → 插入模式下移动到行首/行尾
- `<leader><CR>` → 清除搜索高亮
- `<leader>rc` → 打开配置文件

## Git & 终端
- `⌘G` → 打开 Git 目录下终端

## LSP 相关
- `<leader>h` → 悬浮提示
- `gd / gD / gi / go / gr` → 定义/实现/类型定义/引用
- `<leader>rn` → 重命名符号
- `<leader>,` → 代码操作
- `<leader>t` → 打开 Trouble
- `<leader>- / <leader>=` → 上一个/下一个诊断
- `<c-f>` (插入模式) → 签名帮助

## 其他工具
- `U` → 打开撤销树
- `<leader>y` → 打开 neoclip（剪贴板历史）
- `⌘B` → 打开文件树
- `⌘Y` → 在当前文件位置打开 Yazi
- `<leader>?` → 查看 buffer 内快捷键（which-key）
